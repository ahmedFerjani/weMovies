This project is a coding challenge proposed by a recruiter as part of a technical evaluation. It is developed using Symfony framework and demonstrates my approach to solving the problem

# Cinema Website Project

We need to code an amazing app, this is a cinema website, which looks like **Allocine**.

The goal is very simple:  
You have **2 pages**; the site must list all cinema genres on the left menu with the first best movie, its description, and a play video. When you select a genre, a new list of movies according to the selected genre should be displayed. When you click on a movie, a popup should appear, showing information about the movie, and giving the user the possibility to rate the movie using a **5-star rating system**. You can also search for a movie via the **search bar** with an autocomplete input.

---

## Project Requirements

In this project, you need to:

- **Create a Symfony application**
- **Manage API authentication & logic** with Symfony
- **Use and manipulate JSON API data**
- **Implement algorithms with the DRY principle** (Don't Repeat Yourself)
- **Manage assets with Webpack**
- **Use Docker and/or Docker-Compose**
- **Create an HTML template with a clean design** using stylesheets

---

## Additional Information

- **User registration & login** is not required.
- **Keeping user ratings** is not required.
- You must create an account on **TheMovieDB** and use their API.
- You need to deliver your code on a **public Github** repository.
